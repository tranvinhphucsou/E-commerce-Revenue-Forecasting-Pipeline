# E-commerce-Revenue-Forecasting-Pipeline
Built an end-to-end machine learning pipeline to forecast daily revenue for a Vietnamese fashion e-commerce business over a 548-day future horizon, from 01/01/2023 to 01/07/2024. The project was based on a multi-table retail dataset including historical sales, orders, order items, customers, products, promotions, inventory, web traffic, returns, reviews, payments, shipments, and geography data.

The forecasting task was transformed from a time-series problem into a supervised regression problem, using historical daily sales as the main target source and enriching the model with business-driven features. Key feature engineering included calendar effects, weekday/weekend patterns, payday windows, double-day shopping events, Fourier seasonality, Tet holiday proximity, promotion intensity, FOMO effects near promotion endings, post-sale demand dips, and safe lag features from historical revenue, web traffic, and inventory stockout patterns.

Trained LightGBM regression models with log-transformed targets to reduce revenue skewness and improve prediction stability. The model was validated using TimeSeriesSplit to preserve temporal order and evaluated using MAE, RMSE, WAPE, and R². SHAP-based interpretability was also applied to identify the key drivers of revenue, supporting more explainable business decisions around promotion planning, demand forecasting, inventory allocation, and logistics preparation.
